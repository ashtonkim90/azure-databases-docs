# Azure Database for PostgreSQL flexible server: August 2026 release

We're excited to announce the August 2026 version of Azure Database for PostgreSQL. Starting August 5, 2026, the service automatically onboards all new servers to this latest version. The service upgrades existing servers during their next scheduled maintenance.

This version introduces a range of new features and enhancements, resolves known issues, and includes essential security patches to ensure optimal performance and security.

## Engine version changes

- No PostgreSQL minor version change.


## Features

- No new features.


## Improvements 

- No new improvements.


## Known issues fixes

- Multiple security fixes and hardening improvements to enhance platform security and reliability.
